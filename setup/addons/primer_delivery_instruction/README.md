# Primer Delivery Instructions

Lab module for **Module 5** and **Exercise 03**.

Install after the Docker stack is up:

1. Restart Odoo so it sees `/mnt/extra-addons`.
2. Enable developer mode.
3. Apps → Update Apps List.
4. Search **Primer Delivery Instructions** → Install.
5. Settings → Users → your user → extra rights **Primer Delivery / User** (or Manager).

What you should be able to show:

- A **Primer** app menu with a list of instructions.
- A smart button on a confirmed sales order.
- User cannot delete; Manager can.

This is the kind of “small custom document / extra field on Sales + Inventory” work that shows up inside wholesale implementation jobs, not a full ERP rewrite.
