Contacts + products import

25–35 min Prereq: Module 1, empty-ish portfolio DB CSVs in setup/sample-data

Demand theme

The Upwork post Odoo freelancer needed: setup ERP, modules, API, data import. Send portfolio & quote listed “Data import (clients, products, etc.)” in scope next to module setup and API. Full ERP specialist posts also expect master data work. Import is not glamorous. It is how implementations actually start, and it is visible in a before/after screenshot.

Do this on primer_portfolio

Files:

  • setup/sample-data/contacts.csv
  • setup/sample-data/products.csv

Odoo import: list view → Favorites / cog → Import records (wording: Import). Map columns carefully.

Contacts

  • is_company 1/0
  • country_id by name “United States” — use the search on the mapping if the ID field fights you
  • customer_rank / supplier_rank so they show as customer vs vendor
  • Maya Chen is a person; after import, open her and set Company to Harborline if the CSV did not parent her (many first imports miss parent_id). Fixing that in the UI and screenshotting the fix is allowed — real projects do this.

Products

  • Type column: in 18 you may need to map to the current product type fields (type values historically product, consu, service). If the wizard complains, create one product by hand, export it, and match the header names. That export-first trick is the professional move; screenshot it.
  • Do not invent categories that do not exist; map to All / Saleable or create categories first.
  • You opened both CSVs and know which columns will need remapping.
  • Import test on 1 row, then the rest. No traceback left on the wizard.
  • Before: empty customers list. After: Harborline, Northwind, vendors. Product list with internal references HB-*.

Never import into production on the first try

Duplicate the database (database manager) or use a throwaway DB. Imports create rows that chatter will not explain. This is also what you tell clients.

Done when

  • At least 3 companies and 3 products exist from CSV, not only from the UI.
  • You have an exported template from Odoo itself for next time.
  • You wrote down one mapping gotcha (type, country, category).

What to show on Upwork

  • Before/after screenshots, same filter, same window size.
  • The CSV (sanitized) in the portfolio folder.
  • Proposal: “I import contacts and products from CSV using Odoo’s import wizard, after an export of a sample row so field names match the version you run. I do this on a duplicate database first.”
  • Do not claim ETL/API middleware unless you built one. This exercise is the wizard. API is a later track (XML-RPC/JSON-2).
