How to learn this primer

Odoo is a product you operate, not a book you finish. The unit of progress is a sitting that produces a screenshot, a database state you can reopen, or a module folder.

Session rules

  • Timer on. 25–45 minutes. If you overflow, stop at a checklist item, not mid-form.
  • One database intent. primer_learn is for breaking things. primer_portfolio is for clean captures.
  • Talk while you click. Even if you are not recording, narrate the why. That becomes the Loom later.
  • Write the done-when answers from memory before you look them up. Wrong answers are the point.
  • Do not install every app. CRM, Sales, Inventory, Purchase, Invoicing. Add Website only if you take that optional track.

Retrieval beats re-reading

Each module ends with recall prompts. Close the page. Answer out loud or in progress/TRACKER.md. Then reveal the quiz answers.

What “portfolio packing” means

Upwork clients who posted Odoo implementation jobs asked applicants for previous implementation experience, modules implemented, and portfolio & quote. They did not ask for a certificate screenshot. Pack:

  1. A dated folder: portfolio/YYYY-MM-harborline/
  2. 6–12 PNGs with filenames that tell the story: 03-quotation-sent.png
  3. A loom-script.md even if the video is unlisted
  4. A 4-sentence case blurb you can paste into a proposal
  5. For custom work: the module folder, not a zip of the whole Odoo source

Do not fake client names as real clients

Harborline is a lab company. On Upwork say “lab implementation / demo database” until you have a paid project. Lying about clients is how profiles die.

Suggested first week

  1. Day 1: Setup module + first screenshots
  2. Day 2: CRM + Sales module
  3. Day 3: Exercise 02 (lead-to-cash Loom)
  4. Day 4: Inventory module
  5. Day 5: Accounting module (shorter if taxes confuse you — stop at posted invoice)
  6. Day 6: Custom module + Exercise 03
  7. Day 7: Review day + Exercise 01 packing

If a sitting goes badly, do not “catch up” by skipping recall. Repeat the lab on primer_learn.
