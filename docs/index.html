How this is supposed to feel

Efficient

One sitting, one outcome. Prerequisites on every page. A “done when” box you can fail honestly. No 6-hour binge of official docs.

Sticky

Recall prompts after each lab. A spaced review schedule. One progress tracker in the browser and as markdown you can commit.

Stack, cost, owner

Local Docker Community is the lab. Odoo.sh is mentioned so you can talk about it; it is Enterprise-only and not required. Do not spend money. This repo is meant to live under GitHub user Rayoque as odoo-primer. Enable Pages from the docs/ folder — steps in SHIP.md.
