What Odoo gigs actually sell

Qualitative read of public Upwork job posts, project catalog cards, the Odoo hire page, and freelancer work-history titles. No invented job counts, rates, or “80% of gigs.”

Method

I opened public pages (job applications, catalog services, hire/odoo-freelancers, browse/odoo-development) and listed the modules and deliverables the buyers wrote down. This is a snapshot, not a market study. Re-run the search before you rewrite your profile headline.

Themes that showed up

1. Full-module implementation

Buyers name a cluster: CRM, Sales, Inventory/Stock, Accounting/Invoicing, Purchase, sometimes HR, Projects, POS, Manufacturing. They want configuration, users, and training, not a theoretical ERP essay. Wholesale distribution posts add allocation from on-hand and incoming stock, invoices from deliveries, vendor bills, chart of accounts, custom documents.

2. Customization and custom modules

Catalog titles repeat customization, module development, and report writing. Job text includes “basic customization & automation,” “develop or modify custom modules,” Studio (Enterprise). This is why Module 5 is a module, not a website theme.

3. Data import and integrations

“Data import (clients, products),” API, Shopify/payment/shipping listed on profiles and in scope. The primer gives you a CSV exercise. API/Shopify is a later track — do not put it on the profile until you have a lab for it.

4. POS + Inventory + Sales (retail)

A catalog service is literally “Odoo POS, Inventory, and Sales Module Implementation” (warehouses, lots, barcodes, quotations, delivery orders). POS is not in the first five modules; Inventory + Sales still transfers.

5. Website / eCommerce

Present: catalog “high-conversion Odoo website,” work-history lines like “Odoo Website Updates” and “Finish a Odoo Ecommerce.” Real, but in the open implementation posts sampled it was not the center of gravity. Treat it as track B.

6. Migrations, upgrades, reporting

Profiles sell version upgrades, Community/Enterprise, custom reports (PDF/XLS). Not built as a full module here. After Module 5 you can add a QWeb report as a sixth sitting if a job mentions documents.

Decision: Module 5 = custom modules

Higher overlap with (1)(2)(6) and a git-shaped portfolio artifact. Website remains an optional later lab using the same products from Harborline.
