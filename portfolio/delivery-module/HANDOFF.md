# Handoff — Primer Delivery Instructions

Lab module path: `setup/addons/primer_delivery_instruction`

## Depends

- `sale_management`
- `stock`

## Install

1. Mount addons at `/mnt/extra-addons` (already in compose).
2. Restart Odoo, developer mode, Apps → Update Apps List.
3. Install **Primer Delivery Instructions**.
4. Settings → Users: grant **Primer Delivery / User** or **Manager**.

## Rights

| Group | Read | Write | Create | Delete |
|---|---|---|---|---|
| User | yes | yes | yes | no |
| Manager | yes | yes | yes | yes |

## What to demo

Sales order → Instructions smart button → handling note. Primer menu list.

This is a lab module for the Odoo Primer, not a client deliverable until the names are changed.
